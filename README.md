# 🏋️ Fitness Tracker Application

A responsive, web-based **Fitness Tracker** built using **HTML**, **CSS (Bootstrap)**, and **Vanilla JavaScript**. Easily log multiple workout entries, track durations and calories, view workouts in both table and card formats, and store all data locally using the browser’s LocalStorage.

---

## 🚀 Features

- ➕ Add multiple workout entries dynamically
- ✏️ Edit existing workouts with validation
- ❌ Delete workouts (if duration ≤ 100 mins)
- 🔍 Real-time search by name, date, type, etc.
- 🗂️ View switch: Table View and Card View
- ✅ Inline form validation with messages
- 💾 LocalStorage data persistence
- 📱 Responsive and mobile-friendly UI
